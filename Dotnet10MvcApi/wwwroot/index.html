Multi-Paradigm Web Architecture

Experience 6 web application paradigms hosted seamlessly out of a single ASP.NET Core process. From zero-latency static landing pages to real-time Blazor Server, Vue 2 SPAs, MVC Razor, and Piranha CMS.

Runtime: .NET 10.0 (x64)
Database: EF Core Jet (Access) + SQLite

GET / Fastest TTFB

Static Landing Page

Physical HTML/CSS landing page served directly from wwwroot/index.html with zero server-side rendering overhead.

✓
When to use: Marketing portals, documentation hubs, static landing pages requiring sub-millisecond load times.
✗
When NOT to use: Stateful interactive pages requiring server-side database binding or authentication.
Launch Landing Page (Current)
GET /portal Petite-Vue Reactive

ASP.NET Core MVC Portal

Server-rendered Razor views with standard HTML forms, Bootstrap 4 layout, and Petite-Vue for lightweight DOM reactivity.

✓
When to use: Search-engine optimized (SEO) public marketing portals, transactional e-commerce pages, and form workflows.
✗
When NOT to use: Complex desktop-grade SPAs requiring continuous fluid UI state transitions without page reloads.
Launch MVC Portal (/portal)
GET /app Zero-Build ES Modules

Vue 2.x SPA

High-traffic single page application using native ES modules directly in browser — zero Node.js build tools required.

✓
When to use: High-concurrency client-heavy dashboards and interactive web apps with minimal server state memory footprint.
✗
When NOT to use: Content pages heavily dependent on strict public web search crawler indexing.
Launch Vue 2 SPA (/app)
GET /blazor MudBlazor UI

Blazor Server SPA

Real-time C# web application powered by MudBlazor components and SignalR WebSockets under dynamic route prefixing.

✓
When to use: Internal backoffice applications, admin toolkits, and intranet SPAs leveraging full C# domain logic.
✗
When NOT to use: Massively concurrent public websites with tens of thousands of simultaneous socket connections.
Launch Blazor Server (/blazor)
GET /blogs & /articles Piranha CMS v12

Piranha CMS Editorial Engine

Headless & SSR publication engine for blogs, tech articles, and dynamic block types (HeroBlock) backed by SQLite.

✓
When to use: Editorial blogs, news releases, technical articles, and dynamic content managed by non-technical creators.
✗
When NOT to use: Custom operational business APIs or complex transactional forms.
Blogs (/blogs) Articles (/articles)
GET /manager & /scalar/v1 Admin & OpenAPI

CMS Admin & REST APIs

Full admin management portal (/manager) alongside controller-based REST endpoints documented with Scalar OpenAPI (/scalar/v1).

✓
When to use: Site content management, administrative tasks, mobile app backends, and programmatic API integrations.
✗
When NOT to use: End-user web interface browsing.

Unified Monolith Authentication

Cookies issued by MVC or Blazor Server (.AspNetCore.Cookies at Path="/") are shared seamlessly across all paradigms.
